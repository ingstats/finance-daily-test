# 팀 데일리 만들기 — 전체 진행

교육생이 한 마디(P1)로 시작하면 이 순서대로 끝까지 진행한다. 교육생은 비전공자다. 설명은 짧게, 한 번에 한 가지만 부탁한다.

## 원칙
- 각 단계는 해당 스킬을 열어 그대로 따른다. 단계가 끝나면 **확인 기준**을 직접 확인하고 한 줄로 알린다.
- **[직접] 단계**(로그인·비밀번호, 키·토큰 붙여넣기, 권한 '허용', 약관 동의)는 Claude가 하지 않는다. 화면을 그 자리까지 열어 두고, 아래 안내 문구로 부탁한 뒤 "다 했어요"를 기다린다.
- 화면 제어는 내장 브라우저(없으면 Claude in Chrome)로 한다. 메뉴 이름이 바뀌었으면 '목적'으로 찾는다. 같은 동작이 두 번 실패하면 멈추고 교육생에게 화면을 보여 달라고 한다.
- 운영 중인 다른 뉴스레터(예: AX Daily)의 저장소·앱·Apps Script·예약 작업은 건드리지 않는다.

## 0. 준비 확인 (1분)
- 브라우저에서 github.com, developers.kakao.com, script.google.com을 열어 로그인 상태를 본다. 안 돼 있으면 [직접] 로그인.
- Gmail 커넥터가 연결돼 있는지 본다(없으면 연결을 부탁).
- 작업 폴더: `/home/claude/daily/` (설정 파일 초안을 여기서 만든다).

## 1. 기획 대화 (약 10분) → daily-design
확인 기준: newsletter.yaml·editorial.md·indicators.json 초안이 생기고, 교육생이 섹션·지표를 확인함.

## 2. 사이트 개설 (약 10분) → daily-github
확인 기준: `https://<아이디>.github.io/<저장소>/`가 열리고 샘플 호가 보임.

## 3. 카톡·반영기 설치 (약 35분) → daily-kakao
확인 기준: Apps Script `checkAll` 결과가 모두 OK, 교육생 카톡 '나와의 채팅'에 시험 메시지 도착.

## 4. 첫 호·지표 (약 15분) → daily-run(시험 모드) + daily-market
- 설정 파일 3개와 첫 호를 사이트 반영 초안으로 올린다(daily-run 4~8단계, `--first`).
- Apps Script에서 `collectMarketNow` 실행 → 지표 1년치가 사이트에 나타남.
확인 기준: 사이트에 우리 팀 이름·첫 호·지표가 보임.

## 5. 구독 (3분)
- 교육생 휴대폰으로 사이트 → '카카오톡으로 받기' → 이름 → 카카오 동의. 환영 메시지와 첫 호가 '나와의 채팅'에 오면 성공.

## 6. 매일 자동화 (약 10분) → daily-schedule
확인 기준: 예약 작업 2개 등록, 다음 평일 실행 시각 표시.

## 7. 팀원에게 알리기 (5분)
- 무료 단축 링크(TinyURL 등, 별칭 `hc-<팀영문>-daily`)를 화면 제어로 만들고 QR 이미지와 안내 문구를 만든다.
- 카톡 메시지 링크는 단축 링크가 아니라 github.io 주소다(카카오 앱에 등록한 도메인만 허용).

## 이어하기 (P2) — 실제 상태로 판단
| 단계 | 확인 방법 |
|---|---|
| 1 | 작업 폴더 또는 저장소의 newsletter.yaml에 id·name이 채워져 있는가 |
| 2 | github.com/<아이디>/<저장소> 존재, Settings › Pages에 주소 표시 |
| 3 | script.google.com에 '<이름> 발송기' 프로젝트, 실행 기록의 `checkAll` 결과 |
| 4 | 사이트 data/index.json에 이 뉴스레터 id의 호가 있는가 |
| 6 | 예약 작업 목록(list_triggers)에 '<이름> 발행' |
가장 앞의 미완료 단계부터 이어 한다.

## [직접] 단계 안내 문구 (그대로 보여 준다)
- 로그인: "브라우저에 ○○ 로그인 화면을 열어 두었어요. 직접 로그인해 주시고, 끝나면 '다 했어요'라고 말해 주세요."
- 키·토큰: "보안상 키는 제가 옮기지 않아요. 화면의 ○○ 값을 복사해서, 열어 둔 Apps Script 스크립트 속성 '○○' 칸에 붙여넣고 저장해 주세요."
- 권한 허용: "Google이 권한을 묻는 창이 떴어요. '고급 → (프로젝트 이름)으로 이동 → 허용'을 눌러 주세요. 본인이 만든 스크립트라 안전합니다."
