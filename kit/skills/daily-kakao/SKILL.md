# 카톡·반영기 설치 (화면 제어)

Apps Script 템플릿 프로젝트: TFT가 공유한 「팀 데일리 발송기 템플릿」 링크(kit/README.md). 이 프로젝트에 Code.gs(카톡)·Site.gs(사이트 반영)·Market.gs(지표)가 들어 있다. 코드는 고치지 않고 **스크립트 속성**만 채운다.

## A. Apps Script 사본 (약 10분)
1. 템플릿 링크를 연다 → 왼쪽 **개요(ⓘ)** → 오른쪽 위 **사본 만들기**. 사본 이름을 `<name> 발송기`로 바꾼다.
2. **프로젝트 설정(⚙)** → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**로 Claude가 넣는다:
   `NEWSLETTER_ID`(newsletter.yaml id), `NEWSLETTER_NAME`(name), `SITE_URL`(site_url), `GITHUB_REPO`(github_repo) → **스크립트 속성 저장**.
3. **배포 → 새 배포** → 유형 **웹 앱** → 다음 사용자 인증 정보로 실행 **나**, 액세스 권한 **모든 사용자** → **배포**.
   [직접] 권한 승인 창: "계정 선택 → '고급' → '<프로젝트>(으)로 이동(안전하지 않음)' → 허용". 본인이 만든 스크립트라 정상이다.
4. 배포 결과의 **웹 앱 URL**(…/exec)을 복사해 스크립트 속성 `WEB_APP_URL`에 넣는다(비밀 값 아님, Claude가 입력).

## B. 카카오 디벨로퍼스 앱 (약 10분)
5. `developers.kakao.com/console/app` → **앱 생성**: 앱 이름 `<name>`, 회사명 `하나캐피탈`, 카테고리 '금융' → 저장.
   (카카오 서비스로 오인될 이름은 쓰지 않는다.)
6. **앱 키**에서 **REST API 키** 위치를 보여 준다. [직접] "REST API 키를 복사해서 Apps Script 스크립트 속성 `KAKAO_REST_API_KEY`에 붙여넣고 저장해 주세요."
   클라이언트 시크릿이 '사용함'이면 같은 방식으로 `KAKAO_CLIENT_SECRET`.
7. **플랫폼 → Web → 사이트 도메인**: `https://<아이디>.github.io` (경로 없이).
8. **카카오 로그인 → 활성화 ON**. **Redirect URI**에 WEB_APP_URL을 그대로 등록.
9. **카카오 로그인 → 동의항목 → 카카오톡 메시지 전송(talk_message)** → **선택 동의**, 동의 목적 "매일 아침 팀 데일리 요약을 본인 카카오톡으로 보내기" → 저장.

## C. GitHub 토큰 (약 5분)
10. daily-github 3절. [직접] 토큰 생성·복사 → 스크립트 속성 `GITHUB_TOKEN`에 붙여넣기.

## D. 연결·시험 (약 10분)
11. 편집기 위 함수 목록에서 **setup** 선택 → **실행**. (처음이면 권한 승인 [직접])
    실행 로그의 **발신자 연결 주소**(…/exec?owner=…)를 브라우저로 연다 → [직접] 카카오 로그인·'카카오톡 메시지 전송' 동의 → "발신자 연결 완료".
12. **testToMe** 실행 → 교육생 카톡 '나와의 채팅'에 "[시험] … 연결 확인"이 오면 성공.
13. **checkAll** 실행 → 모든 줄이 OK인지 확인. 없음·실패가 있으면 그 줄의 항목을 다시 한다.
14. newsletter.yaml `kakao_api` = WEB_APP_URL. (사이트 '카카오톡으로 받기' 버튼이 이 주소로 신청을 보낸다)

## 문제가 생기면
| 증상 | 확인 |
|---|---|
| 카카오 화면 KOE006 / redirect 오류 | 8단계 Redirect URI가 WEB_APP_URL과 한 글자도 다르지 않은지 |
| KOE101 / 앱 키 오류 | 6단계 KAKAO_REST_API_KEY 값(앞뒤 공백) |
| 허용되지 않은 링크 | 7단계 사이트 도메인 = SITE_URL의 https://아이디.github.io |
| insufficient scopes | 9단계 동의항목, 11단계 동의 화면에서 '카카오톡 메시지 전송'에 체크했는지 |
| GitHub 쓰기 실패 401/403 | 토큰 만료·저장소 선택·Contents 쓰기 권한 |
