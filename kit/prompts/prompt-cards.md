# 프롬프트 카드 (대괄호만 바꿔서 붙여넣기)

| 카드 | 언제 | 붙여넣을 문장 |
|---|---|---|
| P1 시작 | 교육 시작 | 하나캐피탈 [재무팀] 데일리 뉴스 사이트를 처음부터 만들어 줘. 매일 [조달·금리·신용평가] 소식과 [국고채 3년·원/달러] 지표를 보고 싶고, 평일 8시에 카톡으로 받고 싶어. |
| P2 이어하기 | 중간에 끊겼을 때 | 데일리 뉴스 사이트를 어디까지 만들었는지 확인하고 다음 단계부터 이어서 해 줘. |
| P3 지표 바꾸기 | 숫자를 바꾸고 싶을 때 | 데일리 사이트에 [WTI 유가]를 추가하고 [NASDAQ]은 빼 줘. |
| P4 소식 바꾸기 | 기사 구성이 마음에 안 들 때 | 데일리 뉴스에서 [보험사] 기사는 줄이고 [자동차금융] 기사를 늘려 줘. 바꿀 내용을 먼저 보여 줘. |
| P5 팀원 초대 | 완성 후 | 팀원에게 보낼 데일리 카톡 구독 안내 문구와 단축 링크, QR 이미지를 만들어 줘. |
| P6 문제 해결 | 카톡이 안 왔을 때 | 오늘 아침 데일리 카톡이 안 왔어. 원인을 찾아서 고쳐 줘. |
| P7 확장(시연) | 강사 시연 | 데일리 사이트에 [제도·지정 현황]처럼 [자동차금융 규제 추진 현황] 탭을 추가해 줘. |
